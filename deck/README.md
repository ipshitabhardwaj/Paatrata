# Pitch deck

`Paatrata.pptx` is generated by `build.js` in the same visual language as the web app
(concrete textures, Le Corbusier colours, the façade illustration, credited Chandigarh photos,
real screenshots of the app).

```bat
cd deck
npm install
npm run build
```

If `../evaluation/results/latest.json` exists, the Evaluation slide shows the measured numbers;
otherwise it says the run is pending. Re-run the build after every evaluation run.

Speaker notes for every slide are inside the .pptx (View → Notes).
Screenshots live in `assets/`; retake `ui_compile.png` after a real Gemini compile.
